ABOUT ECOCYCLE

Make responsible recycling easier to choose.

EcoCycle is a demonstration website concept designed to help people understand e-waste, explore responsible disposal options, and estimate potential material value.

⌕

Inform

Explain common e-waste categories, environmental concerns and safer disposal steps in plain language.

₹

Estimate

Let users enter item weights and view an indicative example value range, without promising a guaranteed payout.

⌖

Connect

Demonstrate how location search and collection requests could work when connected to verified providers.

Important demo limitation

This version is a front-end prototype built with HTML, CSS, JavaScript and jQuery. Collector listings, distances and payout rates are sample data. Location search uses browser geolocation when permission is granted, but does not currently query a live collector database. The request form previews a request locally and does not submit it to a real collector or save it to a server.

NEXT STEPS FOR A LIVE VERSION

From prototype to real service.

01

Register and verify collectors

Build a backend database and a process for validating collector identity, authorization, accepted materials and service areas.

02

Connect real maps and geocoding

Use a map/geocoding provider and calculate distances from actual collector coordinates. Request browser location only when the user chooses it.

03

Store collection requests securely

Add server-side validation, consent, secure contact handling, request status updates and notifications before accepting real bookings.

04

Maintain current payout rates

Collect quotes from participating recyclers and show the date, unit, item condition assumptions and exclusions for every rate.
